# v0.5 Relay contract

Status: SDK foundation implemented
Target release: Orbitkeep v0.5.0

Relay carries commands, events, status, and handover messages between trusted
components. It is transport infrastructure, never canonical Mission state.
Receiving components must apply accepted messages through Orbitkeep Core; a
successful Relay publish does not prove that a workflow mutation occurred.

## Envelope and authentication

Every envelope declares protocol version `1.0`, a globally stable message ID,
stream ID, positive per-stream sequence, message kind, UTC send time, Silo and
Silo-instance identity, signing-key ID, JSON payload, SHA-256 payload digest,
and Ed25519 signature. Optional correlation and causation IDs connect request
and event chains. The signature covers the canonical JSON representation of
every field except the signature itself, including ordering and provenance.

Unknown envelope and sender fields are rejected. The receiver resolves the
public key from trusted registration state rather than accepting key material
inside the message. Digest or signature mismatch fails closed.

## Delivery semantics

- Ordering is strict and contiguous within each stream; streams are independent.
- Re-publishing an identical retained message ID is an idempotent duplicate.
- Reusing a retained message ID with different content is a conflict.
- Replay is cursor-based (`afterSequence`) and bounded by both a request limit
  and transport retention.
- A cursor older than the retained window returns
  `RELAY_REPLAY_WINDOW_EXCEEDED`; the consumer must resynchronize from an
  authoritative snapshot rather than guessing missing messages.

`InMemoryRelayTransport` is the v0.5 reference implementation used for contract
and UAT tests. It is intentionally process-local and non-durable. Redis,
network endpoints, retry workers, dead-letter handling, and cross-Silo runtime
operations remain v0.8 work. The public `RelayTransport` interface and
`relay-envelope.schema.json` are the compatibility boundary those transports
must preserve.
